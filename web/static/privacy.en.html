Privacy Policy

Effective 2026-11-23

This policy explains how fast question (https://fast-question.com), run by yyj2046 as an individual (the "operator"), handles personal information. Local mode, which you install and run only on your own PC, does not talk to the operator's server and is not covered by this policy.

  1. 1

    Information we process

    We do not automatically collect conversation content. Apart from the default usage guide added at sign-up, the only questions and answers we store are those you add on the screen or by import, or that a Claude you connected sends with the add tools. Over a remote connection (the claude.ai connector, remote MCP, or the Claude panel on the screen), Claude stores questions and answers only when you ask it to add or change them. The Claude Code plugin that you install on your own PC can, in a project folder that is already in your knowledge base, prompt Claude to add facts it confirmed in the session when you ask a question or when Claude finishes a response, so Claude may then add questions and answers without your request.

    Sign-in: your GitHub user number and login name, or your Google account identifier. We do not store email addresses, real names or phone numbers.

    Account: account number, sign-up and deletion times, hashes of sign-in sessions and access tokens (the original values are not stored), token names, the names and redirect addresses of connected programs, browser type (User-Agent), and the IP address used at sign-up.

    Stored content: categories, questions, answers, evidence (file paths and hashes, a random id of the PC that added it, git information, web addresses, notes) and change history. File contents themselves are never sent to the server.

    Claude panel: the Anthropic API key you register (stored encrypted, with only the last 4 characters kept as they are) and the model you choose. Conversations are not stored.

    Service records: account number, key actions such as sign-ins and tokens, and error details. They do not contain IP addresses, token values, questions, answers or search terms.

  2. 2

    Purposes

    We use this information only to sign you in and tell accounts apart, to store and search questions and answers and connect them to Claude, to prevent abuse of sign-ups and requests, and to handle failures and recovery. We do not use it for advertising, analytics or sale.

  3. 3

    Retention and deletion

    Stored content and account information are kept until you delete your account. When you delete it, access stops immediately and the data is erased after 30 days; only the account number and the sign-up and deletion times remain.

    A sign-up IP address is erased by the next sign-up or by a periodic job that runs once a day after it is 1 day old, so it is gone within 2 days. Service records are erased after 14 days. The copy of service records kept in the server container's standard output is managed by size, not by time (30 MB at most), and the oldest part is erased when it exceeds that size. We do not keep per-request access logs (IP address, User-Agent). Sign-in sessions are valid for 30 days after last use (90 days at most), and personal access tokens for up to 180 days.

    Expired information is erased automatically. Erased information remains in backup copies for about 30 more days, so it takes up to 61 days for a deleted account to disappear from every copy.

  4. 4

    Disclosure to third parties and processors

    Apart from the transfer to Anthropic described in section 5, we do not provide personal information to third parties. We provide it only when required by law and only to the extent required.

    Server operation and backup storage are entrusted to Amazon Web Services Korea LLC. Data is stored only in the AWS Seoul region.

    You sign in directly on the GitHub or Google screen, and that step follows each company's privacy policy.

  5. 5

    Information sent to Anthropic

    When you register your API key in the web Claude panel and send a request, the conversation and the repository content Claude reads with its tools (questions, answers, evidence, categories) are sent each time over HTTPS to the API of Anthropic, PBC (USA, privacy@anthropic.com). This is done to produce the response you asked for; retention and processing follow Anthropic's privacy policy and the terms between you and Anthropic. Nothing is sent if you do not use the panel or delete the key. When you connect Claude Code on your PC, Claude Code sends the data itself.

  6. 6

    Your rights

    You can view, edit and delete items on the screen at any time, and in the connection panel you can download your whole repository as a file or delete your account. Items deleted on the screen disappear from lists and search but remain in the repository and its change history until you delete your account. Send other requests to yyj2046@gmail.com. We answer within 10 days and may verify that the requester owns the account. A representative may also make a request.

  7. 7

    Operator access

    The operator can access stored data to handle failures and restore backups. Stored data is encrypted only at the disk level. API keys are also encrypted with a key inside the server, so the operator can decrypt them. The operator does not view data for any other purpose.

  8. 8

    Security measures

    All connections are accepted over HTTPS only. Sessions and tokens are stored only as hashes, and API keys are stored encrypted. Each account has its own data file, backed up once a day; the backup storage blocks public access and is encrypted. Server access is limited to the operator's SSH key.

  9. 9

    Cookies and browser storage

    We use only the two cookies needed for sign-in (__Host-fq_session keeps you signed in, __Host-fq_login checks a sign-in for 10 minutes). We use no advertising or analytics cookies; if you block cookies you cannot sign in. Screen settings such as the theme, recent searches and panel state, and Claude panel conversations, are kept in browser storage.

  10. 10

    Children under 14

    People under 14 may not use the service. If we learn that one has signed up, we delete the account.

  11. 11

    Privacy officer and contact

    Privacy officer: yyj2046 (yyj2046@gmail.com)

    Send questions, complaints and requests about personal information to the address above.

  12. 12

    Changes to this policy

    When we change this policy, we announce it on the screen from 7 days before it takes effect (30 days for important changes).
